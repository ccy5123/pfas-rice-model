## 2. 기본 구성 전환 (`validation/default_switch.py`)

- 규칙·예상을 `a9549f4`에 먼저 커밋하고 실행. **재분배 지상부 + 지질 결합 경로**가 다섯 전이 종말점 모두에서
  이전 기본(4구획 자유 음이온)보다 0.3 이상 낫고 4구획+지질과 0.1 이내(D1), Yamazaki 0.380 ≤ Fit B 1.198(G1),
  질량 보존 5e-16, 1회 1.7초 → **전환**. `model_api.DEFAULT_SHOOT="redistributed"`, `DEFAULT_LIPID_LOADING=True`.
- 이전 기본은 `api.FOUR_POOL_FREE`. 모든 수송 파라미터(`*_fit`, `*_rec`, 지질 상수 6개)는 4구획으로 적합한 값이고,
  재분배 지상부는 새 적합 파라미터를 추가하지 않습니다.
- 예상하지 못한 것: Yamazaki 낟알을 대부분 2–7배 높게 계산(PFPeA 7.1×, PFUnDA 7.3×, PFOA 3.2×).

## 3. 지금의 핵심 결과 (자세히는 `CLAUDE.md` §6)

- 독립 데이터(기본 구성): Tang 0.640 · Kim 0.469(구간 0.154) · Li 0.358 / 0.510 → 불확실성 범위 ×3.1.
  이전 기본은 1.714 · 2.329 · 1.260 / 1.682(×48). 이 세 자료는 기본 구성 선택에 쓰였으므로 이 점수와 범위는 낙관적일 수
  있습니다(파라미터는 맞추지 않음). 전환에 쓰지 않은 자료가 다음 시험입니다.
- Yamazaki(지질 상수 표본 내): 0.380(뿌리 0.090, 짚 0.253, 낟알 0.619).
- 역추정(Kim PFOA 현미): 0.214 µg/L, 측정 0.0787의 2.7배(95% 0.106–0.433, 측정값 미포함). 이전 기본 16.4배.
- 경로: PFOA 낟알 유입의 80%가 물관, 20%가 체관(`apportionment`); 뿌리 유입의 74%가 토양, 26%가 체관 재순환.
- 기본 구성에서 결과를 크게 움직이는 미측정 입력(`default_sensitivity.py`): `Km`(1.27 log), `E_m`(0.13),
  `retention`(짚 0.11, 낟알 0.23), `lam_grain`(낟알 0.06), 고사엽 처리(짚 0.05).
- HYDRUS: PFBA 낟알 6.90 → 0.69(용탈), PFDoDA 47.9 → 38.6(완충).
- 운반체 vs 우회로: 추가는 필요, 어느 쪽인지 미결(4구획 기준 1.078 vs 1.093, bootstrap 0.368).

## 4. 새로 드러난 것 — 다음 사전 등록 후보

- **어린 이삭의 농도 정점**: 재분배 지상부는 이삭이 생긴 순간부터 증산류의 일정 몫(`lam_grain` 0.05)을 주므로,
  출수 약 2주 전 작은 이삭에서 낟알 농도가 수확값의 약 3.3배까지 올랐다가 희석됩니다(4구획은 이삭 건물에 비례해
  정점 없음). 이삭 몫을 이삭 크기에 비례시키는 수정이 후보이며, 바꾸면 모든 전이 점수가 바뀌므로 규칙을 먼저
  등록해야 합니다. Li 2025 출수기 낟알 TF는 엇갈립니다(PFHxA·PFBS는 모델보다 높고 PFOA·PFOS는 낮음).
  Yamazaki 낟알 과대의 일부가 이 정점에서 올 가능성이 있습니다(미검증).
