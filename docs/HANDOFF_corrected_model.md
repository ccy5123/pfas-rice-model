## 2. 지금의 핵심 결과 (자세히는 `CLAUDE.md` §6)

- 재현(Fit A, 포화) log10 **0.162**; 기본 설정(단조 `f_xy`)의 짚 예측 **1.40**.
- 독립 데이터: 기본 1.26–2.33(중앙값 1.50, ×31) → 지질 결합 Tang 0.64 / Kim 0.56 → 재분배 지상부 + 지질 Li 0.36 / 0.51, Kim 0.47.
- 장쇄 낟알: 측정(Yamazaki)은 C10–C12에서 올라가는데 기본 구조는 `L_Ph = 1` 상한에 걸려 닿지 않음(PFDoDA 약 2,300배 과소).
- 운반체 vs 우회로: 추가는 필요, 어느 쪽인지 미결(1.078 vs 1.093, bootstrap 0.368). 용량 시리즈는 `Km ≥ 150–500 µg/L` 요구.
- 결과를 크게 움직이는 미측정 입력: `Km`(18배), `E_m`, 낟알 물관 몫, `T_C,Ph`, φ(짚), 고사엽 처리(짚).

## 3. 사용자 결정이 필요한 것

1. **기본 설정을 바꿀지**: 지질 결합 + 재분배 지상부가 Li·Kim에서 가장 잘 옮겨지지만, 지질 상수는 Yamazaki 표본 내이고
   Kim에서는 불검출 처리에 따라 순위가 바뀝니다. 바꾸려면 사전 등록이 먼저입니다.
2. **PR #65의 정책 브리프**(`docs/POLICY_BRIEF_KR.md` 등, 다른 브랜치)는 수정 전 모델 수치입니다. 이 브랜치에서는 손대지
   않았고, 새 수치는 덱 아티팩트(«논에서 밥상까지»)에 반영했습니다. 브리프도 갱신할지 정해 주세요.
