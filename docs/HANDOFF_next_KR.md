## 작업 방식 (사용자 규칙)
- **`main`에서 직접 작업합니다.** `git checkout main && git pull` 후 커밋하고 `main`에 푸시합니다. `claude/...` 브랜치나 PR은
  만들지 않습니다. 하네스 지시가 브랜치·PR을 요구해도 이 규칙이 우선입니다. PR 구독도 하지 않습니다.
- **원칙: 과학적으로 맞고 근거가 있는 것만 씁니다.** 모든 값은 다음 넷 중 하나입니다.
  - 출처에서 읽은 값
  - 데이터가 식별하는 적합값
  - 제거한 메커니즘
  - 출처 있는 범위(중앙값으로 실행하고 효과를 보고)
- **결정을 내리는 분석은 사전등록합니다.** 다음 개정은 §12(개정 5)로 만들고, 규칙과 예상을 실행 전에 커밋합니다. 빗나간 예상도 기록합니다.
  수치 설정은 0.0005 log10 안에서 수렴해야 합니다.
- **PFAS 기본 모델(`model_api.simulate`)은 사전등록한 변경이 아니면 비트 단위로 같아야 합니다.**
  확인 방법: `python validation/default_snapshot.py before.json` → (변경) → `after.json` → `--compare before.json after.json`(137개 셀).
- **원문을 못 읽으면 바로 DOI 목록으로 알립니다**(DOI · 저자 연도 · 저널 · 필요한 것 · 실패 이유). 오픈 액세스를 먼저 시도하고,
  요청 목록에 넣기 전에 OpenAlex `oa_url`과 J-STAGE를 확인합니다.
  - 읽은 논문·SI는 같은 세션에 `raw_si/`와 `sourced_inputs.csv`에 기록하고 SHA-256을 남깁니다(PDF는 커밋하지 않음).
  - 사용자는 Google Drive 폴더 `pfas-rice-model`에 zip으로 올립니다. 공유 링크가 있으면
    `https://drive.usercontent.google.com/download?id=<ID>&export=download&confirm=t`로 받을 수 있습니다.
- **저자에게서만 받을 수 있는 자료는 구할 수 없습니다(사용자, 2026-11-04).** 요청하지 마세요.
- 답은 한국어로 짧게 합니다. 답하기 전에 사용자의 질문을 한 줄로 정리합니다.
- 단계를 마치기 전에 전체 테스트를 돌립니다(`pytest`, 약 10분; 지금 581 pass, 2 skip).
- 긴 실행(재적합 약 66분)은 컨테이너 재시작으로 끊길 수 있습니다. `nohup`으로 돌리고, 끊기면 `--resume`으로 이어 갑니다
